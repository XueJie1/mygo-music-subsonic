# Subsonic for MyGo Music

[English](README.md)

一个给 [MyGo Music](https://github.com/egoist/mygo-music) 用的插件，把兼容
Subsonic 的服务器变成音乐源：[Navidrome](https://www.navidrome.org)、Airsonic、
Gonic、Supysonic、LMS、Subsonic 本身，以及其余同类服务器。

## 安装

装好应用后，打开这个链接：

```
mygo-music://install-plugin?repo=XueJie1/mygo-music-subsonic
```

或者在 **设置 → 插件** 中点 **+**，粘贴仓库地址。插件是纯 JavaScript，没有构建
步骤，也不需要下载发布包。

想直接从这个文件夹试用，把它复制到应用的插件文件夹（**设置 → 插件 → + →
打开插件文件夹**），然后启用它。

## 设置与登录

打开 **设置 → 插件 → Subsonic**，填写：

| 设置 | 说明 |
| --- | --- |
| **服务器地址** | 服务器地址，例如 `https://music.example.com`、`http://192.168.1.5:4533`，或者挂在子路径下的 `https://example.com/music`。没写 `http://` 会自动补上。 |
| **用户名** | 插件登录使用的账号。 |
| **密码** | 该账号的密码。 |

点 **登录** 会向服务器核对这三项设置。登录只对「这组服务器地址 + 用户名 + 密码」
有效：改动其中任意一项后都需要重新登录，不会把旧的登录状态用到没人核对过的账号上。
服务器拒绝密码时，对话框会直接说明，而不是继续保留旧的登录状态。

这个插件没有自己的登录网页：**登录** 核对的就是上面三项设置，填好它们就等于登录。
应用弹出的对话框说「将在插件打开的页面中完成登录」，那是给需要网页登录的插件用的
统一文案；对这个插件，直接在 **设置 → 插件 → Subsonic** 里填写或修改即可。

**退出登录** 只是让应用先忘掉这个账号，再次登录时仍使用上面填写的设置，因为
Subsonic 本身没有可结束的会话。

插件自己显示的提示（包括登录提示和错误信息）跟随应用设置里选择的语言：English 或
简体中文；没有对应翻译时用英文。

请求按 Subsonic 的要求签名：`token = md5(密码 + 盐)`，每个请求都用新的盐。密码本身
不会发出，只保存在本机的插件设置文件里。

插件需要「访问任意网站」的权限，因为服务器地址由你自己填写（包括局域网地址）。
它只会和你填写的地址通信。

## 功能

- **首页** —— 为你挑选的一组歌曲，然后是最近添加、最近播放、最常播放和星标专辑，
  以及艺人、播放列表和流派。
- **星标歌曲** 和 **星标专辑** —— 服务器上的星标就是应用里的「喜欢」和「收藏专辑」，
  心形和星标按钮会直接改到服务器上。
- **搜索** —— 歌曲、专辑、艺人和播放列表，输入时给出建议。
- **艺人、专辑、流派、随机** —— 各自有独立页面，流派页会列出该流派的歌曲和专辑。
- **播放列表** —— 列出、新建、重命名、删除、添加、移除和排序歌曲。排序通过重写
  播放列表完成，因为 Subsonic 没有 move 接口。
- **电台** —— 随机播放全部、星标混合两个电台。
- **歌词** —— 支持 OpenSubsonic `getLyricsBySongId` 的服务器会显示同步歌词。
- **Scrobble** —— 播放歌曲会向服务器提交 scrobble，服务器的播放次数和最近播放
  因此保持准确。
- **封面和艺人图片** 用同一个令牌从服务器获取，并在整个会话里保持同一个 URL，
  应用因此只缓存一次。

## 音质

应用的 **音质** 设置对应服务器的 `stream` 接口：

| 音质 | 向服务器请求的内容 |
| --- | --- |
| **无损** | `format=raw`，服务器上的原文件（`flac`、`wav`、`m4a` 里的 ALAC/AAC、Ogg Vorbis 等） |
| **高** | mp3 320 kbps；如果本来就是不超过 320 kbps 的 mp3，则原样播放 |
| **标准** | mp3 128 kbps |

转码在服务器上完成，所以没有配置好转码（例如没有 `ffmpeg`）的服务器请使用
**无损**，或使用不需要转码的曲库。应用无法播放的格式一律请服务器转成 mp3。

## 不做什么

- 播客、评论、关注艺人和「收藏的播放列表」不在 Subsonic API 里，所以插件不提供。
- 只显示同步歌词；没有时间轴的纯文本歌词在歌词页上无处安放。
- 专辑列表只显示前 500 项，因为 API 的浏览接口在插件的页面模型里没有分页。

## 开发

测试会让插件对着自己起的一个小型 Subsonic 服务器运行，并通过一个代替应用的
`host` 调用插件：

```sh
npm test
```

测试覆盖 URL 与令牌签名、数据映射、分页、星标、播放列表及其编辑、串流格式选择、
歌词和插件自己的页面。
